# Unreal Engine 5 на Blueprints — полный курс от нуля до своей игры

Цель курса: пройти путь от установки движка до **собранной (упакованной) игры**, которую можно запустить на любом ПК без редактора. Всё делается на **Blueprints** — визуальном программировании, без C++.

Актуально на октябрь 2026: последняя версия — **Unreal Engine 5.8** (последний крупный релиз ветки UE5; UE6 анонсирован, ранний доступ ожидается в конце 2027). Всё, что здесь написано, работает в UE 5.4–5.8; где есть отличия — это отмечено.

## Как проходить

1. Читай главы **по порядку**. Каждая заканчивается **практикой** и **чек-листом** — не переходи дальше, пока чек-лист не закрыт.
2. Делай всё руками в редакторе, а не просто читай. Один час практики полезнее трёх часов видео.
3. Глава 11 — сквозной проект: по шагам собираешь полноценную игру, используя всё из глав 1–10.
4. Застрял — смотри главу 12 (отладка и типичные ошибки), потом спрашивай Claude: в репозитории есть скилы `unreal-blueprint-mentor` и `unreal-game-builder` (см. ниже).

## Claude в помощь: коннекторы и скилы

Что подключить, чтобы Claude мог помогать «на все 100%»:

| Что | Зачем | Как подключить |
|-----|-------|----------------|
| **Плагин «Unreal Engine Skills»** (официальный, от Epic Games) | Claude управляет редактором Unreal напрямую через MCP: создаёт акторы, Blueprints, материалы, Niagara, виджеты, State Tree, запускает тесты. Работает только на твоём ПК, где запущен редактор | claude.ai → Customize → Plugins → найти «Unreal Engine Skills» → Install. Затем Claude Code **локально** (не в облаке), в папке проекта Unreal. Следуй инструкции скила `unreal-mcp` из плагина |
| **GitHub** (уже подключён) | Хранить курс, заметки и сам проект игры (через Git LFS для ассетов) | Уже работает |
| **Веб-поиск** (WebSearch / TinyFish, уже есть) | Искать свежую документацию Epic и ответы на форумах | Уже работает |
| **Claude Docs** (уже есть) | Вести учебный журнал/дизайн-документ игры с комментариями | Уже работает |
| **Canva** (уже есть) | Иконки, обложка игры, постеры для страницы в Steam/itch.io | Уже работает |

Скилы в этом репозитории (лежат в `.claude/skills/`, подхватываются автоматически):

- **`unreal-blueprint-mentor`** — режим наставника: объясняет понятия UE, проверяет твои Blueprint-графы, задаёт задания и не делает всё за тебя.
- **`unreal-game-builder`** — режим «собрать игру»: дизайн-документ → прототип → вертикальный срез → сборка, с чек-листами по каждому этапу.

Подробно о том, как установить плагин и с чего начать — в [главе 13](13-resursy-i-dalshe.md#claude--unreal-как-подключить-плагин).
