# Рикошет

3D-игра для iPhone (three.js, без сборки): у героя одно оружие, его нужно бросить и подобрать обратно.

- Запуск локально: `python3 -m http.server 8765` в корне репозитория → http://127.0.0.1:8765
  (из `file://` не работает: модули и модели грузятся только по HTTP)
- Тесты логики: `node --test tests/*.test.mjs`
- На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой».

## Режимы

- **Аркада** — волны скелетов на арене, 7 героев, перки после каждой волны, рекорды, вызов дня и вызовы друзьям.
- **Приключение** — открытый мир Острова Семи Корон:
  - деревня, семь царств и пещеры;
  - королевы, боссы, 16 поручений ⭐ и книга «Летопись» на 37 страниц;
  - Кузница Грома: улучшения героя за монеты.

  Глава 1 готова целиком, от пробуждения деревни до Праздника Семи Корон.
- **Задания дня** — три задания на день и сундук: чем больше дней подряд, тем он богаче.

Монеты общие для всех режимов. Тратить их можно в магазине (облик героя, оружие и следы) и в Кузнице.

## Управление

- Стик слева — бег.
- Кнопка справа — бросок. Если вести её вбок, поворачивается камера; если вниз — бросок отменяется.
- Любой другой палец поворачивает камеру.
- Оружие возвращается, только если его подобрать или нажать ↩. Поймал на лету — следующий бросок ×2.

В настройках: стик справа (для левшей), автоприцел и «Автобросок». С автобросками можно играть одной рукой: остановился — оружие летит в цель само.
