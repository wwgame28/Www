# Рикошет

Аркадный шутер для iPhone: одна пуля, которую нужно подбирать обратно. Веб-игра, без сборки.

- Дизайн: `../docs/superpowers/specs/2026-10-11-ricochet-design.md`
- Запуск локально: `python3 -m http.server 8765` в этой папке → http://127.0.0.1:8765
  (из `file://` не работает: модули и модели грузятся только по HTTP)
- Тесты логики: `node --test tests/*.test.mjs`
- На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой».

Управление: веди пальцем — бежать, короткий тап — выстрел. Пуля возвращается только если подобрать её
(или поймать на лету — тогда следующий выстрел ×2).
