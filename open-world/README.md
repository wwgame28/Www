# Открытый мир

Браузерная 3D-игра: бесконечный генеративный ландшафт, который строится из шума с сидом. Один сид — всегда один и тот же мир.
Океаны, озёра, пляжи, равнины, леса, пустыни, горы и снежные вершины, смена дня и ночи, облака, звёзды.
Можно гулять, бегать, плавать и летать.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # проверить сборку, http://localhost:4173
npm test         # тесты генерации: детерминизм, швы чанков, коллизии
```

## Управление

| | Компьютер | Телефон |
|---|---|---|
| Идти | WASD или стрелки | джойстик слева |
| Бег | Shift | джойстик до края |
| Камера | мышь (захват курсора) | свайп справа |
| Прыжок / вверх в полёте | Space | «Прыжок» |
| Полёт | F | «Полёт» |
| Вниз в полёте | C или Ctrl | «Вниз» |
| Пауза | Esc или P | кнопка ⏸ |
| Отладка (FPS, чанки, draw calls) | ~ (Ё) или F3 | настройка «Показывать FPS» |

Геймпад: левый стик — ходьба, правый — камера, A — прыжок, Y — полёт, LB — бег, B — вниз, Start — пауза.

## Как устроено

- `src/config.js` — все числа баланса и настройки генерации.
- `src/world/` — шум (`noise.js`), рельеф и биомы (`terrain.js`), данные чанков (`chunkgen.js`, считается в `worker.js`),
  загрузка чанков с LOD (`chunks.js`), растительность на `InstancedMesh` (`vegetation.js`), вода, небо, облака, частицы.
- `src/player/` — ввод (клавиатура, мышь, геймпад, тач) и физика игрока.
- `src/ui/` — экраны, HUD с компасом, отладочный оверлей, стили с токенами палитры.
- `src/audio/` — звук на Web Audio: ветер, прибой, птицы, сверчки, шаги по разным поверхностям (всё синтезируется).
- `src/save.js` — сохранение сида, позиции и настроек в `localStorage`.

Мир делится на чанки 64×64 м. Вокруг игрока они генерируются в Web Worker'ах с пятью уровнями детализации
(64, 32, 16, 8 и 4 клетки на сторону), дальние выгружаются. Трава появляется только рядом, у деревьев есть упрощённые дальние модели.
